Piropiro User Interface

  • Categories: RESEARCH
  • Tags: XR Interface Haptics Unity Electronics

吹き戻しを用いて息の検出を行うユーザーインターフェースと、それを用いて身体部位や息に対する拡張感を提示するアプリケーションを開発した。

様々な体験を高い臨場感と直感性を維持したまま、単一のインターフェースで提供することを目指した。体験の例として、カメレオンのように長い舌を伸ばして獲物を捕獲する体験、ドラゴンのように口から炎を吐く体験、吹上パイプを吹く体験を制作した。
