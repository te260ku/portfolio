Path-Code

定められたルートを特定の移動方法で辿ることで、隠蔽された情報にアクセスするシステムを開発した。

本プロジェクトでは、従来の位置情報に時間軸を取り入れることを考えた。このコンセプトは2つの重要な要素を内包しており、第一にすべての位置情報にはそこに至るまでに辿ってきた道が存在すること、第二に位置情報の変化にはそれに要した歩く、走るなどの動作が付随するということである。位置情報がもつこれらの要素をふまえ、定められたルートを特定の移動方法で辿ることで、隠蔽された情報にアクセスするシステムを開発した。
