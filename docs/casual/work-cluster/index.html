clusterワールド制作

バーチャルSNS「cluster」にて、バーチャルにおける特異で新しい体験を軸に、様々なワールドを制作している。

Acrobat Shooter

https://cluster.mu/w/93518ff8-e020-4224-bd28-5b91d6b49a2c

アクロバティックな空中戦が楽しめる新感覚シューティングゲーム。全面ジャンプ台のステージを駆使して、飛行する敵を撃ち落とす。

Award

Cluster Gamejam 2021 in SUMMER パワー賞

注文の多い料理店 in cluster

https://cluster.mu/w/4f43313e-b399-4135-a2d7-16224337ff6d

未来の「小説」をテーマにした作品。宮沢賢治の小説『注文の多い料理店』の物語を体験できるワールド。作中に登場する若い紳士になりきって、扉に書かれた数々の注文をこなしながら「山猫軒」を奥へと進む。

Award

大加速祭2021「ワールド制作チャレンジ」 佳作

Ghost Hacker

https://cluster.mu/w/373342a0-4ee8-499f-90fd-77bae39582dd

壁や床をゴーストのようにすり抜けながらフィールを駆け回るアクションゲーム。Cluster Gamejam 2020 in WINTER 応募作品。

Zanzo

https://cluster.mu/w/1ca647f2-79da-4bd1-969f-129b2bb16191

時をテーマにした対戦型ソードアクションゲーム。時を止めることで現れるプレイヤーの残像を狙って、紅葉舞う庭園を駆け巡る。プレイヤーの軌跡表示や空中廊下の出現など、物理法則を超えた演出による新感覚の熱い駆け引きを楽しめる。

Award

clusterゲームワールド杯 本戦出場

みんなのサバイバル

https://cluster.mu/w/b67bc278-5bd6-40a6-bef5-fd31f0631d60

無人島で自給自足の生活を送るワールド。森で収穫したキノコや、海で釣った魚を料理する。誰かが釣ってきた魚を料理したり、みんなで一緒にキノコの群生地に足を運んだり、バーチャル空間で生まれるゆるいつながりを模索した。

Award

Cluster Gamejam 2020 in SUMMER COMP賞

Midnight Royale

https://cluster.mu/w/da404986-d824-40d7-ac2b-367dd3d56555

蛍が舞う夜の森を舞台にした対戦型FPS。広大なフィールドを探索しながらターゲットを狙撃するバトルロワイアル形式。

Award

clusterゲームワールドコンテスト2020 特別賞
