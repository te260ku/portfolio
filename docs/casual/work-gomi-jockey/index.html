Gomi Jockey

  • Categories: CASUAL
  • Tags: Electronics

入れるゴミの種類によって音楽のテンポが変わるDJゴミ箱。

燃えるゴミを入れると音楽のテンポが上がり、燃えないゴミを入れると音楽のテンポが下がる。その時々の状況に応じた心地よい空間を調整して作るために、自然とゴミの分別行為が行われることをねらった。

アイデアの発散と収束プロセスおよびプロトタイピングの練習として制作した最初の作品。最終的なアイデアに至るまでの過程とそれぞれのタイミングで使用した発想技法を記録した。
