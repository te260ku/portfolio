Oto-Kabe

身の回りの机や壁を叩いて遊ぶARリズムゲーム。物理空間のあらゆる平面をインタラクト可能な物体に書き換えてゲームに取り込む。

POP1 Kill Extractor

VRゲーム「POPULATION: ONE」のプレイ映像から、自動的にキルシーンを抽出してキル集を作成するツール。

Unity ROS Action Planner

UnityからROSのトピックに任意のメッセージを送信するためのインターフェースを実装した。

Path-Code

定められたルートを特定の移動方法で辿ることで、隠蔽された情報にアクセスする暗号化システムを開発した。

Doremi Squash

空間の幾何情報を活用したインタラクティブなMRゲーム。部屋の壁や床にボールを当ててスカッシュをプレイする。

恋風

いつでもどこでも誰かとすれ違う感覚を味わえる装置。足音や匂いをインタラクティブに提示することによって、視覚に依存しないバーチャルなすれ違い体験が可能。

Emotional Ice

表情によって尖ったり凹んだりする製氷モーダル。IoTにおける食べることによるインタラクションの可能性を検証した。

θ館ワールド

コロナウイルスによる遠隔授業の広まりを受け、大学の講義棟をバーチャルSNS「cluster」にて再現した。

TimeAchine

人間の歩行動作を行うSCARA型ロボットを用いて、時間と空間からの脱却を表現する。

Tiger Hunting

闇夜に身を潜める野生のトラを駆除するVRシューティングゲーム。3Dプリントした実寸大のライフルを持ちながら体験する。
